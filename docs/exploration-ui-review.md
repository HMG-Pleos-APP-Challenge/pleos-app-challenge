# 탐험 UI 개선

## 구현
- 지역 선택 화면을 지도 카드와 탐험률·진입 안내로 나눴다. 지도에 실제 번들 도로와 명소를 표시하고 크기를 확대했다.
- 기록 중/꺼짐을 구분하는 지역 상세 안내를 추가했다. 기존 수동 시작·중지 콜백을 그대로 사용한다.
- 지도 범례와 ‘탐험한 구역’ 등 사용자 중심 문구를 적용했다.
- 명소 수집 여부를 카드에서 구분하고 기존 명소 상세·구역 목록 진입을 유지했다.
- 화면 폭에 따라 가로/세로 배치로 전환한다.

## 협업 범위
- ExplorationMapScreen.kt 내 지역 목록·지역 상세 표현 변경. 공통 ExplorationMapPreview 구현과 함수 시그니처는 변경하지 않았다.
- 홈에서 사용하는 지도 미리보기 동작은 그대로다. 홈·점령·MainActivity·공통 모델/route·Gradle·Manifest는 수정하지 않았다.
- 새 지도 SDK·DB·모듈을 추가하지 않았고, 탐험률 분모·해금/보상/체류 규칙을 변경하지 않았다.
- 최신 Notion 문서는 도구 접근 오류로 확인하지 못했다. 기존 인터페이스와 로컬 작업 경계를 유지했다.

## 검증
- 최종 코드로 testDebugUnitTest 78개 통과, lintDebug 오류0·기존 경고5, assembleDebug 성공.
- Pleos Connect 2.1.0 API34에서 최종 지도·지역 상세 표시와 프로필→지역 지도→지역 상세 이동 확인.
- 구역 목록의 빈 상태, 명소 상세 진입, Android Back을 통한 지역 상세 복귀 확인.
- 최종 APK의 지도 확대·색상·범례를 실제 화면 캡처로 확인했다.
- 좁은 화면 분기는 코드·컴파일로만 확인했다. 신규 해금·GPS·TTS/실주행은 재검증하지 않았다.

주차 후 확인 문구는 UX 안내이며 주차 판정/주행 중 접근 제한 기능이 아니다. 자동 기록·차량 상태 SDK 연결은 후속 기능이다.
