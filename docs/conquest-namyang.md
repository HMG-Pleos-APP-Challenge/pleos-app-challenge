# 남양읍 점령 구간과 화면 연결

## 데이터 재사용

탐험 브랜치 f18f6e1의 도로 원본에서 남양성지로 OSM way 55055096 v24를 재사용했다.
탐험 내부 reader/세션/100m 셀은 의존하지 않는다. 기존 데이터에는 통행 방향과
노드 위상 정보가 없어 OSM 원본으로 보완했다. 출처와 재생성 방법은
`docs/data/CONQUEST-DATA-NOTICE.md`에 있다.

테스트 구간은 교차로의 공유 노드(도로 그래프 이웃 3개 이상) 사이 3개다.

| 입구 노드 | 출구 노드 | 길이(약) |
| --- | --- | --- |
| 414929156 | 4641680981 | 143m |
| 414929158 | 4641681201 | 133m |
| 3420754234 | 4641681262 | 154m |

각각 양방향 총 6개 구간이며 OSM 기본 양방향 규칙으로 분리했다. 현장 통행 규정이나
실차 GPS 정확도를 검증했다는 뜻은 아니다. 지도는 로컬 선형을 그리는 Canvas이며
상용 지도 SDK·타일 서비스·내비게이션이 아니다.

## 완주 판정

`DirectedRoadDetector`는 기존 LocationSample을 소비하고 기존 RoadVisited를 출력한다.
입구 관측 없이 중간에서 시작하면 인정하지 않는다. 입구에서 출구까지 연속 관측 후
출구를 넘어가거나, 출구를 관측한 뒤 교차로 밖으로 진출해야 완료한다. 교차로에서
좌/우회전해 빠져나오는 경우도 허용하되, 도로 안으로 되돌아가는 U턴은 인정하지 않는다.

초기 보수적 정책(실차 보정 전): 정확도 10m 이하·미상 제외, 오차 포함 도로 회랑 20m,
입구 게이트 12m, 샘플 간격 15초 이하, 샘플 간 이동 60m 이하/속도 40m/s 이하,
역행 허용 8m, 완료 전 최소 3개 관측. 이 값은 GPS 잡음/도로 환경 실험 후 변경할 수 있다.
방향·도로를 구별할 수 없는 중첩 후보는 중복 기여를 만들지 않는다.
재시작 시 미완료 통과는 복원하지 않으며 기존 인정 기여는 보존한다.

`ConquestLocationPipeline`은 팀 선택 후 판정한 이벤트만 기존 기여 원장에 전달한다.
팀 선택 전 진행 중이던 통과는 폐기한다. 파일 쓰기 실패 시 완료 이벤트를 메모리에
보관해 다음 샘플에서 재시도한다. 프로세스 종료 시 미저장 pending은 사라질 수 있으며
손실 없는 백그라운드 기록을 보장하지 않는다.

## 화면·공통 조립부

MainActivity의 점령 객체를 `rememberConquestSession`으로 교체하고
기존 source.samples() 샘플을 점령 파이프라인에도 전달한다. 공유 입력을
새로 구독하거나 탐험의 batch.regions 흐름을 교체하지 않는다.
공통 모델·계약·Route·Gradle·탐험/프로필 내부는 변경하지 않는다.

홈·지도·프로필은 같은 점령 요약을 받는다. 지도는 방향 화살표와 팀별 색상을 표시한다.
팀 미선택 상태에서 선택할 수 있고 선택 후 변경할 수 없다. 기본 2개 팀 ID 목록은
세션 생성 인자이며 계산은 3팀 이상도 처리한다. 세션은 foreground에서 30초마다
정산을 확인하며, Android 백그라운드 정각 실행을 구현한 것은 아니다.

MOCK 점령 파일은 `conquest/mock-<datasetVersion>.bin`에 분리한다.
로딩 실패·처리 실패를 표시하며 기존 기록을 초기화하지 않는다.
파일 I/O는 IO dispatcher에서 실행한다.

기존 MockLocationSource는 남양읍 도로 위의 좌표가 아니므로 기존 재생 버튼으로
점령 기여가 발생하지 않는 것이 정상이다. 기존 탐험 Mock 재생은 유지한다.
새로운 시연 경로/모의 시간 도구·실제 SDK 입력은 후속 작업이다.

## 검증과 한계

- `tools/test_conquest_catalog.ps1`: 재생성 해시, 정/역방향 일방통행, 미지원 방향 거부.
- 전용 단위 테스트: 실제 남양읍 geometry → 완주 → 기여 → 요약 → 재시작/정산,
  재통과 중복, 선택 전 이동, 저장 실패 후 재시도, U턴·이탈·GPS/시각 오류.
- 기존 Mock 통합 테스트를 유지하고 전체 단위 테스트·Lint·Debug APK 빌드로 회귀 확인한다.
- Android/Pleos 기기 실행·실주행·UI 시각 검증·실제 Android 파일 원자 교체는 미검증이다.
- 전체 남양읍 탐험 게임은 친구 브랜치에 있으며 이 브랜치로 자동 병합하지 않았다.
