# 남양읍 확대: 저장 전환 준비와 후보 검색

2026-11-12. 앱 활성화 전 단계이며 현재 기본 카탈로그는3개 물리구간/6방향이다.

## 저장 전환 준비

ConquestCatalogMigration.prepare는 같은ID/geometry의 기존 도로가 새 카탈로그에 모두 있는 경우만 처리한다. 기존팀·기여·시각을 복사하고 datasetVersion만 새버전으로 바꾸며 pending도 같은번들에 보존한다. 기존파일은 삭제/변경하지 않는다. 검증한 임시폴더를 atomic directory move로 게시한다. 준비번들의 receipt는 원본fingerprint와 사용자/출처/버전이 일치해야 하며 재시도로 덮어쓰지 않는다.

전용7개 테스트: 복사/원본보존/재시도, 원본변경 충돌, 손상파일, geometry누락/출처분리, 중단임시폴더, 준비큐누락, 다른사용자/알수없는도로. 초기 테스트fixture의1970시각과 임의첫도로 제거 가정을 수정했다. 최종156개 전체테스트와 lint/APK 성공을 확인했다.

이 API는 오프라인 준비용이다. 활성화 전에 구세션 중지, 계정복원 차단의 새경로 검사, 단일세션 소유권을 연결해야 한다. 아직 ConquestSession에서 호출하지 않는다. Windows 파일시스템 테스트를 Android 전원종료 검증으로 표시하지 않는다.

## 후보 검색

RoadCandidateIndex는위경도 격자의 보수적bounding box로 후보를 줄인다. 실제 완주규칙은 기존DirectedRoadDetector 그대로다. 지오메트리의30m 끝점연장과 정책회랑/진입여유를 포함하며 판정중인구간은 현재위치가bounds밖이어도 반드시 포함한다. 원본순서를 유지해 중첩후보 처리도 보존한다. 큰bbox는 전체fallback으로 처리한다.

전역1453방향에서20개마다 선택한 도로에15m이하 간격의 좌표와 출구이탈좌표를 넣어 전체탐색과 이벤트 결과가 같은지 테스트했다. 먼위치의진행중구간 보존과 인근후보감소도 확인했다. 전용2개 및 기존회귀 포함158개 실패0. 이는 전체 도로/실차의 모든 GPS오차 검증이나 p95성능 완료를 뜻하지 않는다. 실제성능측정·전체지도UI·전역활성화는후속이다.

공통모델/Route/친구내부코드/Gradle 변경 없음. 기존자료와 라이선스는 docs/data 고지를 따른다.
