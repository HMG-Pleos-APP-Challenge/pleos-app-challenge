# 지도 탐험·프로필 프로토타입 검토

## 변경 범위
- 홈: 지역 탐험 / 기존 도로 점령 진입 카드, 프로필 버튼.
- 개인 탐험: 지역 지도 → 남양읍 → 지도에서 도로 구역 또는 명소 선택 → 상세. 해금 구역 목록에서도 상세 진입.
- 프로필: 레벨·경험치, 지역·셀 진행도, 명소 도감, 설정.
- SDK 원시 상태·사용자 ID·모의 재생은 설정 → 개발자 도구로 이동. 개발 빌드에서만 노출.
- 기본 표시는 SDK 저장 기록. 모의 기록을 선택하면 상단에 '모의 기록' 표시. 두 기록의 경험치는 합산하지 않음.
- 기록 시작은 남양읍 상세, 중지는 남양읍 상세와 설정에서 가능. 기존 백그라운드 기록/TTS 서비스를 사용.
- 기록을 시작하지 않아도 이전 SDK 기록을 불러와 표시하도록 세션 로딩 경로 확장.

## 공동 작업 영향
- 사용자 지시에 따라 홈 진입 UI와 MainActivity 연결 변경. 최 담당 홈 화면이므로 향후 통합 시 공유 필요.
- feature/conquest 코드와 점령 판정·저장 로직은 변경하지 않음. 기존 ConquestMapScreen 호출 유지.
- core, navigation/Routes, Gradle, Manifest, 공통 모델·인터페이스 변경 없음.
- 공통 계약 v0.1은 공개 Notion에서 공동 승인 대기 상태 확인. 승인 완료로 처리하지 않음.
- 새 DB, 서버, 지도 SDK, 모듈 도입 없음.

## 실행 검증
- Pleos_Connect_2_1_0 API 34 에뮬레이터에 APK 업데이트 설치. 앱 데이터 삭제 없음.
- 홈 → 지역 지도 → 남양읍 이동 확인.
- 지도 명소 마커 → 명소 상세(반경 100m, 연속 120초 안내) 확인.
- 지도 도로 셀 → 선택 구역 강조 지도 및 미탐험 상태 확인.
- 화면 뒤로 버튼으로 부모 화면 복귀 확인.
- 프로필 → 설정 → 개발자 도구 및 모의/SDK 표시 전환 확인.
- 모의 프로필 레벨 4 / 340 XP / 발견 지역 1 / 셀 4 / 명소 1 유지 확인.
- 프로필 → 해금 구역 4개 목록 확인.
- 남양읍 상세에서 SDK 기록 시작, 홈·프로필·설정 이동 후 기록 중 표시 유지, 설정에서 중지 표시 확인.
- testDebugUnitTest: 78개, 실패/오류 0.
- lintDebug 및 assembleDebug 성공.

## 이번 검증의 한계
- 공개 경계·도로·명소를 Canvas로 그린 간단한 지도. 배경 타일·지도 이동·확대 제스처는 없음. 선택 상세에서 확대된 범위를 보여줌.
- 해금 구역 목록은 좌표 정렬 후 최대 30개만 표시. 전체 합계·탐험률은 모든 해금 기록을 포함.
- 이번에는 UI 이동·기록 제어를 검증. 실제 주행, 신규 GPS 해금, 2분 체류와 TTS 음성 재검증을 수행한 것은 아님. 이전 SDK/백그라운드/TTS 검증 문서를 참조.
- 에뮬레이터 툴바의 Back 자동화는 창 좌표 문제로 사용할 수 없어 앱 내부 뒤로 버튼으로 검증. Android BackHandler는 기존 방식으로 연결.
- 커밋 전 사용자 검토 대기. push/PR/원격 병합 없음.
