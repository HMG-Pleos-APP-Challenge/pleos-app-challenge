# 프로필 UI 개선

## 구현
- 레벨·누적 XP·다음 레벨까지 남은 XP를 나의 탐험 여권 카드에 배치했다.
- 장식용 나침반과 기본 호칭 ‘탐험가’를 사용한다. 계정·닉네임 편집·아바타 업로드 기능은 추가하지 않았다.
- 지역 수·탐험 구역 수·도로 기반 탐험률을 각각 이동 가능한 카드로 표시한다.
- 기존 지역·셀·명소 획득 여부에서 첫 발견·첫 구역·첫 명소 달성 표시를 계산한다. 별도 보상·배지 저장·XP 지급은 없다.
- 명소 수집/미수집, 로딩/빈 목록을 구분한다.
- 넓은 화면은 3열 요약, 좁은 화면은 세로 요약으로 구성한다.

## 협업 범위
- ProfileScreen.kt의 표현만 변경. 함수 인자·콜백·XP 규칙·저장소 계약은 그대로 유지한다.
- feature/home, feature/conquest, MainActivity, core, navigation, Gradle, Manifest 변경 없음.
- 최신 Notion 계약·운영 문서는 도구 접근 오류로 이번 작업에서 확인하지 못했다. 로컬 AGENTS.md와 기존 인터페이스를 유지했으며 공동 승인을 완료로 처리하지 않는다.

## 검증
- testDebugUnitTest: 78개, 실패/오류 0. lintDebug: 오류 0·기존 경고 5. assembleDebug 성공.
- Pleos Connect 2.1.0 API34에서 APK 업데이트 설치(데이터 삭제 없음).
- 최종 프로필 화면의 레벨1/0XP/미달성/명소0개 표시와 지역 지도 이동 확인.
- 좁은 화면 분기는 코드·컴파일로 확인했으며, 별도 좁은 기기의 시각적 검증은 하지 않았다.
- 사용자 데이터에 모의 해금이나 XP를 추가하지 않았다. 기록 중 서비스·실주행·TTS 신규 검증은 이번 UI 작업 범위가 아니다.

주행 상태 연동·자동 기록 시작·주차 확인은 이번 변경에 포함하지 않는다.
