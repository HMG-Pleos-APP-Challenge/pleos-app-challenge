# 계정 연결·복원

게스트 Auth UUID를 유지한 채 이메일 연결 → 받은 메일의 링크 인증 → 비밀번호 설정 순서로 영구 계정으로 전환한다. 이메일 발송·자격 정보 입력은 사용자가 주차 상태의 설정 화면에서 직접 시작한다. 비밀번호는 화면 메모리에만 두며 로그·파일에 저장하지 않는다. 토큰은 기존 Keystore 암호화를 유지한다.

복원은 탐험 기록이 없는 기기에서 기록 서비스가 꺼지고 미전송 위치가 없을 때만 허용한다. 기존 기록을 다른 계정에 자동 병합하지 않는다. 이메일 중복/인증 전/오류 응답은 기존 세션을 교체하지 않는다. 복원 성공 후 서버 확정 기록을 불러온다. 익명 계정 복원은 이메일 연결과 비밀번호 설정을 마친 이후에만 가능하다.

Supabase 설정에서 manual linking 및 이메일 인증/발송 정책이 허용되어야 한다. 실제 이메일 인증·새 기기 복원은 사용자 소유 이메일로 수동 검증해야 하며, 코드 빌드·정책 테스트와 구분한다.
