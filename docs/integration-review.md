# 탐험·점령 통합 검토 (2026-11-11)

## 통합 범위
- 유 브랜치 `feature/exploration-profile` 1cc7543과 최 브랜치 `choi` d507eb2를 `integration/exploration-conquest`에서 병합했다. 공통 조상은 afe2157이다. 원본 브랜치와 main은 보존한다.
- 최신 Notion 계약·운영 규칙 조회는 404로 실패했다. 이 문서는 코드에서 확인한 통합 결과이며 공동 승인을 대신하지 않는다.
- 홈에는 탐험·점령·프로필 진입만 둔다. 탐험과 점령의 기존 지도 렌더러를 재사용한다. 프로필에서도 점령 요약으로 이동할 수 있다. 시연은 저장 기록과 명시적으로 구별한다.

## 구조와 충돌 방지
`Pleos 위치 → ExplorationTrackingService → 탐험 세션 + 점령 세션 → 기능별 저장소 → 홈/지도/프로필`

- 탐험은 도로가 포함된 500m 셀 243개, 점령은 교차로 사이 실제 도로 3개·방향 6개다. 셀 ID와 도로 ID를 서로 변환하지 않는다.
- 탐험·프로필: Supabase Auth + PostgreSQL/PostGIS RPC, SQLite 재전송 큐 및 로컬 캐시. 기존 500m 마이그레이션 001~003을 유지한다.
- 점령: 최 담당의 방향별 판정·기여·정산 구현과 로컬 파일을 사용한다. 기본 2팀, 팀 변경 불가, 사용자·방향·반일당 1회 기여, KST 낮 12시 기준 최근 36시간 정산이다. 동률이면 기존 소유 팀이 공동 1위인 경우 유지하고 나머지는 중립이다.
- SDK 구독은 서비스 한 곳에서 수행한다. 같은 샘플을 두 기능에 전달하며 중단·재시작 시 미완주 관측을 초기화한다. 같은 파일은 앱 내 하나의 점령 세션만 열어 UI/서비스의 덮어쓰기를 막는다.
- mock / pleos-emulator / pleos 저장소를 분리한다. 디버그 시연은 메모리에서만 실행하며 SDK 기록에 적용하지 않는다. 저장 오류는 표시한다.
- 사용되지 않던 별도 셀·주간 점령 UI와 SQL을 제거했다. 해당 SQL은 원격에 설치하지 않았으며 DB 삭제 작업은 수행하지 않았다. 최 담당 도로 점령과 경쟁하는 두 규칙을 남기지 않는다.
- SDK 점령 로컬 기록이 있으면 다른 계정 복원을 막는다. 계정에 속한 기록을 잘못 섞지 않기 위한 임시 제약이다.

- HomeScreen: 기능별 지도 미리보기를 받아 조합. 수동 충돌 해결.

- androidTest Manifest에 격리 저장소 통합 probe만 추가했다. 실제 사용자 파일이나 GPS를 변경하지 않는다.

- APK 설치 후 홈 3개 진입과 점령 화면에서 완주·정산 결과를 눈으로 확인했다. 에뮬레이터 위치는 변경하지 않았다. 실제 도로 주행 및 실차 자동 시작 검증을 의미하지 않는다.

## 우선 권고사항
1. **점령 서버 연결**: 현재 다른 기기의 팀 기여는 합산되지 않는다. 방향별 도로 카탈로그와 검증 RPC, 서버 기준 KST 정산을 설계해야 한다. 폐기한 셀/주간 점령 SQL을 실행하지 않는다. 탐험 서버가 연결됐다는 이유로 점령도 연결된 것으로 안내하지 않는다.
2. **정책 확인**: 2팀·팀 변경 불가·반일 1회·최근36시간·낮12시 규칙을 두 담당자가 확정한다. 탐험 500m 셀과 점령 실제 도로의 차이를 사용자 문구에도 유지한다.
3. **실차 상태와 위치 검증**: 현재 에뮬레이터는 android.car 차량 상태 API가 없어 디버그 수동 테스트를 사용한다. 실제 Pleos에서 주행/주차 신호와 정확도 의미, 터널·교차로 오판정을 검증해야 한다. 속도 0만으로 주차로 판정하면 안 된다.
4. **계정 통합**: 설치 단위 사용자 ID와 Supabase Auth UUID의 점령 소유 관계, 이메일 인증 후 다른 기기 복원 정책을 확정한다. 실제 이메일 복원 전 과정은 미검증이다.
5. **오프라인 정산**: 탐험은 30일 큐를 허용하지만 점령은 이미 정산한 낮12시보다 오래된 기여를 거절한다. 지연 업로드 인정 범위와 재정산 정책을 서버 구현 전에 결정한다. 점령의 미저장 완료 이벤트 재시도는 메모리이므로 프로세스 종료에 대비한 영속 outbox가 필요하다.
6. **정산 시점·데이터 확대**: 현재 점령 정산은 조회/전경 갱신 시 계산한다. 백그라운드에서 정확히 낮12시에 실행되는 서버 작업은 없다. 남양읍 전체 점령으로 안내하기 전에 현재 3개 도로 데이터를 확대하고 출처/라이선스를 유지한다.

main 병합 전 상대 리뷰와 위 정책 확인이 필요하다. 통합 APK는 최소 동작 확인용이며 다중 사용자 점령 서비스 완료 상태가 아니다.
